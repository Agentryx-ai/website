# Analytics Event Taxonomy

- Scope: public website analytics for `agentryx-ai.com`
- Principle: collect aggregate product interest and navigation signals without
  identifying visitors.
- Last reviewed: 2026-05-03

This taxonomy is intentionally small. It supports basic website learning while
avoiding personal data collection, session replay, fingerprinting, or behavioral
profiles.

## Collection Principles

- Use first-party, privacy-conscious analytics where possible.
- Do not collect names, email addresses, phone numbers, free-text input, IP
  addresses in raw form, precise location, or device fingerprint identifiers.
- Do not use cross-site ad pixels.
- Do not enable session replay, heatmaps, keystroke capture, or full URL capture
  with query strings.
- Keep event names stable and low-cardinality.
- Prefer counts and coarse dimensions over user-level timelines.
- Set a short retention period until a privacy policy decision says otherwise.

## Common Event Fields

Every event should use the same envelope.

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `event_name` | string | `product_card_opened` | Required. |
| `event_version` | string | `1.0` | Required for taxonomy changes. |
| `occurred_at` | ISO timestamp | `2026-05-03T03:00:00Z` | Generated by client or analytics tool. |
| `route` | string | `/products/agentryx` | Path only. No query string or hash. |
| `locale` | enum | `en`, `ko` | Current visible language. |
| `referrer_type` | enum | `direct`, `internal`, `external`, `search`, `unknown` | Coarse category only. |
| `viewport_class` | enum | `mobile`, `tablet`, `desktop`, `unknown` | Derived from width buckets. |

Do not add raw user agent, IP address, full referrer URL, screen dimensions,
browser plugin data, or stable visitor IDs unless a privacy policy decision
approves it.

## Events

### `route_viewed`

Fires when a public route becomes visible.

Purpose:

- Understand which pages are read.
- Detect broken navigation or unexpectedly low-traffic pages.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `route` | string | `/thesis` | Path only. |
| `route_group` | enum | `home`, `product`, `thesis`, `about`, `press`, `other` | Required. |
| `product_slug` | string/null | `agentryx` | Only for product routes. |

### `product_card_opened`

Fires when a visitor opens or expands a product card, or navigates from a product
card to its detail view.

Purpose:

- Compare product interest without tracking individual users.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `product_slug` | string | `itineva` | Use stable internal slug. |
| `product_status` | enum | `core`, `candidate`, `poc`, `direction`, `unknown` | Match the public product model. |
| `source_route` | string | `/` | Path only. |
| `open_type` | enum | `expand`, `detail_route`, `modal`, `unknown` | Use the actual UI behavior. |

### `external_site_visited`

Fires when a visitor clicks a public external link.

Purpose:

- Understand outbound interest while avoiding full destination tracking.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `destination_type` | enum | `product_site`, `github`, `social`, `press`, `other` | Required. |
| `destination_domain` | string | `github.com` | Domain only. No path or query. |
| `product_slug` | string/null | `agentryx` | If the link is product-specific. |
| `source_route` | string | `/products/agentryx` | Path only. |

Do not collect the full outbound URL unless a privacy policy explicitly allows
it and query strings are stripped.

### `thesis_read`

Fires when the thesis page is meaningfully read.

Purpose:

- Separate accidental page views from actual thesis engagement.

Recommended trigger:

- Fire once when the visitor reaches 50% scroll depth on `/thesis`, or after 30
  seconds of active visibility, whichever happens first.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `route` | string | `/thesis` | Required. |
| `read_signal` | enum | `scroll_50`, `active_30s` | Required. |
| `content_version` | string | `2026-05-03` | Update when thesis content materially changes. |

Do not collect exact scroll depth, reading speed, cursor movement, or copied
text.

### `contact_clicked`

Fires when a visitor clicks a contact link.

Purpose:

- Measure intent to contact without collecting the person's contact details.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `contact_type` | enum | `email`, `social`, `calendar`, `form`, `other` | Required. |
| `source_route` | string | `/about` | Path only. |
| `destination_domain` | string/null | `agentryx-ai.com` | Domain only for web destinations. |

Do not collect email addresses, `mailto:` full URLs, message subjects, form text,
or calendar invite details.

### `language_toggled`

Fires when the visitor changes the visible language.

Purpose:

- Understand language demand and detect broken localization.

Fields:

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| `from_locale` | enum | `en`, `ko` | Required. |
| `to_locale` | enum | `en`, `ko` | Required. |
| `source_route` | string | `/products/itineva` | Path only. |

Do not infer nationality, ethnicity, location, or identity from language choice.

## What Not to Collect Yet

Do not collect these in the current phase:

- raw IP addresses
- full user agent strings
- device fingerprints
- advertising identifiers
- cross-site tracking identifiers
- session replay recordings
- heatmaps
- keystrokes
- mouse paths
- exact scroll timelines
- precise geolocation
- full referrer URLs
- full outbound URLs with paths or query strings
- email addresses or contact form content
- user-level event timelines
- account, payment, or CRM data
- private repository names or internal project URLs

## Requires Privacy Policy Decision

Do not enable these until the privacy policy and consent approach explicitly
allow them:

- cookies or local storage for analytics identity
- persistent anonymous visitor IDs
- IP-based country or city analytics
- full referrer URL collection
- full outbound URL collection
- A/B testing with visitor bucketing
- remarketing or advertising pixels
- CRM enrichment
- newsletter signup analytics tied to email addresses
- contact form analytics tied to message content
- long-term event retention beyond the initial operational need
- sharing analytics data with third parties beyond the selected analytics
  processor

## Naming Rules

- Use past-tense event names: `route_viewed`, `contact_clicked`.
- Use lowercase snake case.
- Keep enum values lowercase snake case.
- Add fields only when they answer a known product or operations question.
- Version the event when changing meaning, trigger timing, or required fields.

## Implementation Notes

- Strip query strings and hashes before sending `route` or `source_route`.
- Classify referrers on the client or analytics edge into coarse categories.
- Use domain extraction for outbound links and discard the path.
- Fire `thesis_read` at most once per page view.
- Fire `route_viewed` once per route transition.
- Treat analytics failures as non-blocking; the website should continue to work.
